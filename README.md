Репозиторий с вымученной версией проекта автодолнения [PAD][PAD][PAD] текстов


### Структурушка:

С датасетами не всё так просто, по росту не пустили в самолёт.
Разархервийруйте(?) zip-архивы, либо используйте свой csv-файл raw_dataset.csv 

```
text-autocomplete/
├── data/                            # Датасеты
│   ├── raw_dataset.csv              # "сырой" скачанный датасет 
│   └── tweets.csv                   # "варёный" датасет
│   └── dataset_processed.csv        # "очищенный" датасет
│   ├── train_samples.csv            # тренировочная выборка
│   ├── val_samples.csv              # валидационная выборка
│   └── test_samples.csv             # тестовая выборка
│
├── src/                             # Весь код проекта
│   ├── data_utils.py                # Обработка датасета
|   ├── next_token_dataset.py        # код с torch Dataset'ами
│   ├── lstm_model.py                # код lstm модели
|   ├── combine.py                   # код обучения модели и замера метрик lstm модели
|   ├── transformer.py               # код с запуском и замером качества трансформера
│
├── configs/                         # yaml-конфиги с настройками проекта
│
├── models/                          # веса обученных моделей
|
├── solution.ipynb                   # ноутбук с решением
└── requirements.txt                 # зависимости проекта
```
